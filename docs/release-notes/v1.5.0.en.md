# FrameForge v1.5.0

v1.5.0 is a major release: the boost engine now works as a transaction and can heal itself after a crash, with new core-scheduling policies, a system-resource arbiter, per-game profiles and a diagnostic Optimize page; the UI moves to a wuxia light/dark glass theme, with several transparency fixes and noticeably faster page switching.

The single-file `FrameForge.exe` is about **7.07 MB** (both watercolor backgrounds and the preview artwork are embedded).

## Boost & rollback

- One-click boost is transactional: all 9 kinds of system changes are recorded first, applied one by one, confirmed, then committed atomically; a failure rolls back only what already ran.
- Crash healing: if the app crashes, loses power or is killed during a boost, the next start reconciles the journal and restores everything; a watchdog process follows the main app and takes over the restore if it exits unexpectedly.
- New `--restore` command-line entry to run a full reconciliation manually.
- Old (v1) journals are migrated to v2 and still restore safely; damaged or unknown-version journals are quarantined instead of being applied.
- Process identity is verified by name + start time + full path, so PID reuse can never target the wrong process.
- Other processes whose affinity we forcibly moved have their original mask recorded in the same transaction and restored on exit.
- Partial hardware conflicts are reported as partial instead of silently claiming success.

## Core scheduling

- New core policies: Auto / P-core first / Single CCD, selectable in Settings.
- Rebalance interval (15–120 s) and load hysteresis (default 2%) are adjustable to avoid migration thrash.
- Topology snapshot exposes CCD / NUMA / SMT / LLC so the core map matches the real layout.

## Resource arbitration & memory trim

- Power plan and system timer are now reference-counted: one-click boost and real-time boost share the same original value and the last release restores it, so they no longer overwrite each other.
- Memory trimming is throttled so it cannot fire repeatedly in a short window.

## Per-game profiles

- New per-game optimization dialog that stores an independent policy per game (8 toggles plus the ideal core set).
- Process keys are normalized to lowercase names, old display-name profiles are migrated and cleaned on save/delete, and the matching profile is applied automatically when a game is boosted.

## Optimize page (diagnostic workspace)

- Rebuilt as a diagnostic workspace: summary at the top, read-only hardware topology (P/E cores, SMT, LLC) on the left, every system setting on the right.
- Side-by-side on wide windows, stacked on narrow ones, scrollable at low heights; 36 px row rhythm and wrapping instead of overlapping text.

## Records & self-test

- The report card now draws the session FPS curve (soft fill + thin line + average line).
- Self-test grew to 70+ checks covering transaction round-trip and v1→v2 migration, shared arbitration between the two engines, conflict/missing/pending reconciliation and core policies.

## Visuals

- **New dual theme**: paper-ink watercolor for day, shadow-blade dark watercolor for night; title bar, pages and cards share one backdrop that stays continuous while resizing and scrolling.
- **Glass cards**: each card composites a blurred backdrop + cream/smoke tint + top sheen once, and child controls sample the same layer.
- **New gauges**: metal ring, large inner dial, vermilion gradient arc with a white end dot and 60 fine ticks; all readings use the app's original sans-serif numerals.
- **Sword icon and core strip**: CPU/GPU dials now carry the sword icon (brightened automatically on the dark theme); the core strip lights only the cores actually used by the active boost.
- **Radar and info strip**: radar axes are CPU / GPU / RAM / frequency / temperature; memory arc, info strip and mode bar were re-proportioned.
- **Global restyle**: nav capsule, segmented control, toggles, buttons, sliders, progress bars and tooltips unified in vermilion + glass.
- **New app icon**: white leather tile with a vermilion bolt, applied to the exe, window, tray and README.

## Fixed

- Child controls each stacking their own glass layer, which made labels brighter than the card and left hard rectangular edges.
- Segmented controls painting the page background inside a card, leaving a crisp right-angled patch.
- The Optimize page's scroll host painting an opaque solid color over the watercolor backdrop.
- The "Restart as administrator" button being covered by the status text, leaving only two white lines.
- Removed the heavy vermilion corner slashes from cards.

## Improved

- Filter and overlay previews now use the built-in watercolor game frame, cover-cropped without stretching; the filter page keeps the draggable A/B divider.
- The boost hero card re-spaced status, title, subtitle, tags, core strip and caption; secondary buttons are translucent so the card texture shows through.

## Performance

- Whole-card appearance cache: each card is pasted as a single bitmap when switching pages.
- Filter/overlay previews are cached per size instead of rescaling the 1024 px source every frame (the main cause of the old stutter).
- Gauge and memory arcs draw with one gradient stroke instead of hundreds of arc segments.
- Pages are pre-built and pre-rendered after startup; static pages refresh every 2 s instead of 1 s.

> If the taskbar still shows the old icon, Windows is caching it: unpin and repin the taskbar item, or run `ie4uinit.exe -show`.

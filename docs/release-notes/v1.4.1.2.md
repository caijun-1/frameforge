# FrameForge v1.4.1.2

## 中文

### 修复

- 修复「检查更新」误报：四段版本号（如 1.4.1.1）在比较前被截成了三段，导致已经是最新版本时仍会提示「发现新版本」。现在会保留修订号，正确判定当前版本。
- 已更新到 1.4.1.1 但每次启动仍被提示更新的用户，安装本版后即恢复正常。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

---

## English

### Fixed

- Fixed a false update prompt: four-part versions (e.g. 1.4.1.1) were truncated to three parts before comparison, so the app kept reporting a new release even when already up to date. The revision number is now preserved.
- If you installed 1.4.1.1 and were still prompted for an update on every launch, this release resolves it.

**Checksum**: see the attached `FrameForge.exe.sha256`.

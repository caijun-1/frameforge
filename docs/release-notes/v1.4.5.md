# FrameForge v1.4.5

## 中文

### 新增

- **RTSS 叠加层（可选）**：装了 RTSS（RivaTuner Statistics Server）的机器，可以把叠加层整个交给 RTSS 的 OSD 绘制。RTSS 把文字写进游戏的呈现链，所以**独占全屏下也能显示**。
  - 叠加层页与设置页都会显示状态：运行中 / 已安装没运行 / 未安装；
  - 没安装可以直接在界面里下载安装（约 7 MB，下载源失败会自动换官方地址）；
  - 已安装没运行时，一键启动 / 停止；
  - 字号（50%–200%）、颜色（白 / 粉 / 绿 / 黄 / 青）、排版（逐行 / 单行）在界面里调，作为内嵌标签写进 OSD 文字，不需要再打开 RTSS 自己的设置界面；
  - RTSS 没在运行时，仍然由 FrameForge 自带的分层窗口绘制，完全不注入游戏。
- **独占全屏下的数字振动**：接入 NVIDIA 驱动的 NVAPI，按当前预设的饱和度抬升驱动的数字振动（DVC），**零注入**拿到跨通道饱和度。独占全屏的滤镜不再只能用 S 曲线近似。
  - 量程按本机实际值换算（0–63 与 0–100 都支持），只升不降；
  - 关闭滤镜或退出程序时还原成用户原来的数值；
  - 非 NVIDIA 显卡自动跳过，回退到 LUT 近似。
- **「我的游戏」扫描结果缓存**：扫描一次后记下时间，下次启动直接读本地列表，不再每次开机全盘重扫；需要时仍可手动重扫。
- **原神**：内置库补充 `Genshin Impact Game` / `yuanshen` 等目录名，并扫描 `<盘符>\miHoYo Launcher\games`，通过米哈游启动器安装的原神也能进「我的游戏」并显示中文名。
- **滤镜预设新增冷色 / 暖色**：追加在通用预设末尾，已保存的预设索引不会错位。

### 改进

- **独占全屏的滤镜拆成两层协作**：gamma LUT 负责亮度 / 对比度 / 色温 / 暗部（逐通道增益），跨通道的饱和度交给数字振动。只有 LUT 生效时不会丢掉亮度类效果，两者同时生效时正好还原整张矩阵，不会重复调色。
- **滤镜不再「过一会儿自己没了」**：切分辨率、重新进入独占全屏、驱动重置都会把 LUT 顶回默认值；现在每 2 秒按上次的矩阵补写一次，NVIDIA App 重放显示设置时也会补写数字振动。
- 叠加层页在 RTSS 运行时自动切到 RTSS 卡片（只留 OSD 样式），并新增状态行说明读数由谁绘制。
- 设置页新增「RTSS 叠加层」卡片：安装进度、启动 / 停止、卸载（卸载后提示重启才能彻底清掉显示钩子）。
- 隐私说明改为准确表述：默认不注入、不装驱动、不读游戏内存；RTSS 叠加是可选第三方组件，非注入路径始终可用。

### 修复

- **误判独占全屏导致饱和度整块丢失**：原来只要系统报告「有全屏程序」就把放大镜卸掉，全屏优化、独立翻转的误报都会踩中，表现出来就是「开了滤镜没反应」。现在按矩阵拆分处理，误报时画面依旧正确。
- **滤镜在切分辨率 / 切全屏后失效**：由上面的周期性补写解决。

### 注意

- RTSS 会向游戏注入自己的 OSD，被反作弊拦截的游戏（如无畏契约）仍可能不显示叠加层；此时关掉「RTSS 叠加」回到自带分层窗口即可，加速与滤镜不受影响。
- 独占全屏下的数字振动只支持 NVIDIA 显卡；AMD / Intel 显卡在该模式下仍用 LUT 的 S 曲线近似饱和度。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### New

- **Optional RTSS overlay**: machines with RTSS (RivaTuner Statistics Server) installed can hand the whole overlay to RTSS's OSD. RTSS writes text into the game's present chain, so **the overlay keeps working in exclusive fullscreen**.
  - The Overlay page and the Settings page show the state: running / installed but stopped / not installed;
  - if it is not installed, it can be downloaded and installed from inside the app (about 7 MB, with a mirror fallback);
  - if it is installed but stopped, one click starts it (and stops it again);
  - size (50%–200%), color (white / pink / green / yellow / cyan) and layout (stacked / single line) are set in the UI and written into the OSD text as inline tags, so RTSS itself never needs manual configuration;
  - when RTSS is not running, FrameForge still draws the overlay with its own layered window and injects nothing.
- **Digital vibrance in exclusive fullscreen**: the app now uses NVIDIA's NVAPI to raise the driver's digital vibrance (DVC) according to the active preset, providing the cross-channel saturation a gamma ramp cannot express with **zero injection**.
  - the range is read from the machine (0–63 and 0–100 are both handled) and values only go up;
  - the user's original level is restored when the filter is turned off or the app exits;
  - non-NVIDIA GPUs are skipped and fall back to the LUT approximation.
- **Cached My Games scan**: the scan time is recorded, so the next start reads the local list instead of sweeping the disk again; a manual rescan is still one click away.
- **Genshin Impact**: added `Genshin Impact Game` / `yuanshen` folder names and a scan of `<drive>\miHoYo Launcher\games`, so installs made through the miHoYo launcher are listed with their Chinese title.
- **New filter presets, Cool and Warm**, appended to the end of the general presets so existing saved indices do not shift.

### Improved

- **The exclusive-fullscreen filter is split into two cooperating layers**: the gamma LUT handles brightness / contrast / warmth / shadow lift (per-channel gains) while digital vibrance handles saturation. A LUT-only path no longer loses the brightness effects, and when both are active the original matrix is reproduced without double-grading.
- **The filter no longer "fades away after a while"**: resolution changes, re-entering exclusive fullscreen and driver resets push the LUT back to default, so the matrix is rewritten every 2 seconds; digital vibrance is re-applied when NVIDIA App replays display settings.
- The Overlay page switches to the RTSS card automatically while RTSS is running (leaving only the OSD style) and adds a status line saying which renderer draws the numbers.
- The Settings page gained an **RTSS overlay** card: install progress, start / stop, and uninstall (with a reboot hint so the display hook is fully removed).
- The privacy note now says it accurately: no injection, no driver install and no game-memory reads by default; the RTSS overlay is an optional third-party component and the non-injection path always works.

### Fixed

- **Saturation vanishing because of a fullscreen misdetection**: the Magnifier used to be dropped whenever Windows reported a fullscreen app, which fullscreen optimizations and independent-flip false positives trigger — the symptom was "I turned the filter on and nothing happened". The matrix split keeps the picture correct even when the report is wrong.
- **The filter stopping after a resolution change or a fullscreen switch**, solved by the periodic rewrite described above.

### Notes

- RTSS injects its own OSD into games, so titles whose anti-cheat blocks it (VALORANT, for example) may still show nothing. Turn "RTSS overlay" off to go back to the built-in layered window; boosting and filters are unaffected.
- Digital vibrance in exclusive fullscreen requires an NVIDIA GPU; AMD / Intel cards keep using the LUT's S-curve approximation in that mode.

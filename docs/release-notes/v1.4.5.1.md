# FrameForge v1.4.5.1

## 中文

### 新增

- **实时加速**：设置页新增「实时加速」开关，开启后常驻后台，把**当前前台程序**提到高优先级，并把它的同名进程（浏览器 / QQ / 微信这类多进程应用的后台进程）提到高于正常——切到浏览器就是浏览器，切到微信就是微信，不需要先选游戏再点加速。
  - 常用浏览器与聊天软件（Chrome、Edge、Firefox、QQ、微信、Telegram、Discord 等）即使不在前台，同名进程也提到高于正常，后台消息拉取和同步更跟手；
  - 同时开启**系统级基础加速**：切到高性能电源计划、把系统计时器精度提到 1ms；
  - 可用内存低于总内存 20% 时，清理系统文件缓存与待命内存（每个进程约 60 秒检查一次）；**不动各进程的工作集**，避免把浏览器 / 微信刚读进来的数据清掉、下次打开反而更慢；
  - 关闭开关或退出程序时逐项还原：被改过的进程优先级恢复原档位、计时器精度还原、电源计划切回原来那一套；
  - 加速页模式卡顶部新增常驻状态行，显示是否开启、当前加速的程序和进程数。

### 注意

- 系统关键进程（桌面、登录、安全组件、svchost、任务管理器等）从不参与加速，FrameForge 自身也排除在外；
- 部分受保护进程会拒绝修改优先级，这类进程直接跳过，不影响其余加速项；
- 电源计划与计时器精度需要管理员权限（程序本身即以管理员身份运行）。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### New

- **Real-time boost**: a new toggle in Settings keeps FrameForge resident in the background and boosts the **current foreground app** to high priority, with all its same-name processes (the background processes of multi-process apps such as browsers, QQ and WeChat) raised to above normal. Switch to the browser and the browser is boosted; switch to WeChat and WeChat is boosted — no need to pick a game and press boost first.
  - common browsers and chat apps (Chrome, Edge, Firefox, QQ, WeChat, Telegram, Discord and others) are raised to above normal even when they are not in the foreground, so background sync and message polling feel snappier;
  - **system-level basics** are applied at the same time: the high-performance power plan and a 1 ms system timer resolution;
  - when available memory drops below 20% of total, the system file cache and standby list are trimmed (checked roughly once a minute); **process working sets are left untouched**, so data a browser or chat app just loaded is not evicted and has to be read from disk again;
  - turning the toggle off or exiting restores everything: the original priority class of every process it changed, the previous timer resolution and the power plan that was active before;
  - the mode card on the Boost page gained a persistent status line showing whether it is on, which program is boosted and how many processes are covered.

### Notes

- Critical system processes (desktop, logon, security components, svchost, Task Manager and so on) are never touched, and FrameForge excludes itself;
- some protected processes refuse priority changes; they are skipped without affecting the other items;
- the power plan and timer resolution need administrator rights (the app already runs elevated).

# FrameForge v1.4.3

## 中文

### 修复

- **浏览器不再被当成游戏**：360 国际版等 Chromium 浏览器（F11 全屏或无边框窗口）不再被识别为游戏、不再被自动加速；Chromium、浏览器与 UWP 外壳的窗口类一并排除。
- **游戏识别改为按证据判定**：内置游戏库、Steam / Epic / WeGame 等游戏目录、Unreal / Unity / Godot 引擎特征，命中任意一项即算游戏，与窗口大小无关——窗口化、小窗口、无边框、全屏都能识别；认不出的程序只有「铺满屏幕 + 读不到进程名，或窗口类属于游戏引擎」时才按游戏处理。

### 新增

- **滤镜新增「暗部场景平衡」与「数字振动」独立开关**：滑杆默认 50、开关默认关闭；两者作为独立增强层叠加在预设或 ICC 之上，使用 ICC 校色时也能单独生效。
- **叠加层排版向小飞机（MSI Afterburner / RTSS）靠拢**：同一台设备的数值合并到一行，设备名（CPU / GPU / 内存）只写一次，占用、温度等数值依次排在后面并按列右对齐；贴角边距从 24 px 收到 10 px，行距与内边距压紧，同一组指标占的面积明显更小；默认改为「竖向 + 左上」，开箱就是贴角窄条。

### 优化

- **叠加层稳定性**：绘制画布、预乘缓冲与 DIB 按尺寸复用，不再每 200 ms 分配几百 KB 内存；DIB 创建失败时直接跳过这一帧，不会往空指针里写导致进程被系统终止；渲染异常每分钟最多记一条日志；显示项全部关闭时自动收起，不再留一条「-- FPS」挂在屏幕上。
- **叠加层去掉「CPU 温度」选项**：AMD 笔记本（如拯救者 R9000P）不通过 ACPI 暴露 CPU 热区，WMI 与 PDH 都读不到，留着只会一直显示 `--`；CPU 占用、GPU 温度等其余指标不受影响。
- **页面排版统一**：五个页面的页面边距与卡片内边距统一为 20 px，区块标题字号提到 10.2 pt（不再小于行标题），切换页面时内容左边缘不再左右跳动；加速页去掉多余的一层内缩与底部空档；健康页在最小窗口高度下十行指标也能完整显示。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### Fixed

- **Browsers are no longer mistaken for games**: 360 Browser and other Chromium browsers (F11 fullscreen or borderless) are no longer detected or auto-boosted. Chromium, browser and UWP shell window classes are excluded as well.
- **Evidence-based game detection**: a match in the built-in game database, a Steam / Epic / WeGame library folder, or Unreal / Unity / Godot engine fingerprints is enough regardless of window size — windowed, small, borderless and fullscreen all work. An unknown app only counts as a game when it covers the screen *and* its process name is unreadable or its window class belongs to a game engine.

### New

- **Shadow balance and Digital vibrance switches** for the filter (slider default 50, switches off by default). Both stack on top of presets or ICC profiles, so they also work while an ICC correction is active.
- **Overlay layout now follows MSI Afterburner / RTSS**: metrics from the same device share one row with the device name (CPU / GPU / RAM) printed once and its values (usage, temperature, ...) laid out in aligned columns; corner margin tightened from 24 px to 10 px, with tighter row pitch and padding, so the same metrics take noticeably less screen space. Defaults are now Stack + Top L.

### Improved

- **Overlay stability**: the drawing canvas, premultiply buffer and DIB are reused by size instead of allocating hundreds of KB every 200 ms; a failed DIB allocation now skips that frame instead of writing through a null pointer (which would terminate the process); render errors are logged at most once a minute; the overlay collapses when every metric is switched off instead of leaving a "-- FPS" badge on screen.
- **Removed the CPU temperature field from the overlay**: AMD laptops (e.g. Legion R9000P) expose no ACPI thermal zone, so WMI and PDH both come back empty and the field could only ever show `--`. CPU usage, GPU temperature and the other stats are unaffected.
- **Consistent page layout**: page margins and card padding are unified at 20 px across all five pages, section headers moved up to 10.2 pt (no longer smaller than row titles), and the content edge no longer jumps when switching pages. The Boost page loses an extra inset and a bottom gap; the Health page fits all ten rows at the minimum window height.

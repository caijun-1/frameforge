# FrameForge 1.6.5

> Overlay HUD redesign and reliability hardening release. Overhauls both the built-in and RTSS overlays with a modern translucent glass HUD backdrop, five unified colour themes and an enlarged hero FPS readout, while unifying the settings preview with the live rendering pipeline and fixing resource-handover persistence, steering races and generic process caching.

## Overlay HUD redesign

- **Modern translucent HUD backdrop (default)**: rounded dark vertical-gradient plate, thin glass border, subtle top sheen and a theme-coloured left accent bar; switchable anytime in the Overlay page between `HUD`, `Subtle` and `None` (`overlayBackdrop=hud|subtle|none`).
- **Five unified colour themes**: Cinnabar (default), Emerald, Neon, Cyber and Mono (`overlayTheme=cinnabar|green|pink|cyan|mono`), shared across the built-in overlay, RTSS output and settings preview; legacy `rtssColor` values (`pink`, `green`, `cyan`) migrate automatically.
- **Clear visual hierarchy**: enlarged bold hero FPS with a compact baseline-aligned `FPS` label; a subtle horizontal hairline separates FPS from hardware rows in stacked mode, vertical hairlines separate groups in horizontal and mini capsule modes, and ambient rows (clock/uptime) right-align independently so they no longer widen CPU/GPU columns.
- **Upgraded RTSS OSD**: shares the same five colour themes, uses inline `<S=...>` tags for a larger hero FPS readout, pads labels to fixed width in stacked mode, and separates groups with `|` in single-line mode with balanced `<C>` close tags.
- **1:1 live preview**: the settings preview now invokes `Overlay.PaintPreview` directly with DPI-aware scaling, eliminating visual drift between the preview card and the in-game HUD.
- **Sharper text shadows & unlock frame**: crisp single drop shadow on dark backdrops, clean four-way outline on transparent backgrounds, and a subtle dashed outline whenever position lock is off.

## Reliability and UX fixes

- **Persisted ownership on handover**: when one-click boost exits first and hands PowerScheme/Timer ownership over to real-time boost, real-time boost immediately persists the updated ownership snapshot to `boost.realtime.journal` so crash recovery always restores the power plan.
- **Accurate original power plan on SHARED overlay**: when one-click boost overlays an active real-time boost as SHARED, its journal captures the arbiter's original power scheme instead of recording `SchemeHigh`.
- **Ghost-journal guard on background steering**: the background ideal-CPU steering worker now verifies the active transaction instance before writing to disk, never overwrites `steerBusy` from `Restore()`, and records non-Auto rebalance updates in the journal.
- **Generic process name cache isolation**: generic executables (such as `Client-Win64-Shipping.exe`) resolved via folder or file version info are no longer written to the permanent name-only cache, preventing stale titles when switching between Unreal Engine games.
- **Safe font-pool & config cache lifecycle**: overlay font-pool cleanup runs at frame boundaries instead of disposing active GDI+ fonts mid-render; `CoreConfig` cache is invalidated immediately on `Settings.Save()`.
- **UI & sync fixes**:
  - Fixed `Settings.Sanitize()` resetting `overlayBackdrop=hud` back to `none` on load;
  - Mini mode now respects the FPS / 1% Low / GPU Temp toggles and includes them in the render cache key;
  - Toggling "Lock position" on the desktop now immediately shows or hides the overlay for dragging;
  - `Ctrl+Alt+O` now syncs the self-drawn overlay toggle switch on the Overlay page;
  - Shutdown now also stops `warmTimer` and `updateTimer`, and `OverlayPage` disposes its `ToolTip`;
  - Tuned minimum-height spacing on the Overlay page to prevent bottom clipping at 840×640.
- **Expanded self-test**: `--selftest` now verifies all 5 themes × 3 backdrops × 3 styles and balanced RTSS `<C>` tags (zh/en string parity 650/650).

## Upgrading

- Replace `FrameForge.exe`; settings and match history remain compatible.
- v1.6.5 enables the new `HUD` backdrop and `Cinnabar` theme by default; if you prefer plain transparent text, switch **Overlay → Backdrop** back to **None**.

# FrameForge v1.4.4.2

## 中文

### 修复

- **AMD 显卡上温度 / 频率 / 功耗仍然显示 —**：1.4.4.1 只调用了带 context 的 `ADL2_Overdrive6_*`，只要其中一步返回失败就整段放弃。AMD 驱动版本之间差异很大，现在改成两层回退：
  - 接口：先试 `ADL2_*`（带 context），失败再用老式 `ADL_*`（全局接口）；
  - 数据：温度按 Overdrive6 → Overdrive5 → OverdriveN 逐条试，频率按 Overdrive6 CurrentStatus → Overdrive5 CurrentActivity 逐条试，功耗沿用 Overdrive6 的四种电源类型。
  任何一条能读出合理数值就会显示，并记住这条路径，之后不再重复试错。
- **开机自启时驱动还没就绪**：读不到数据不再永久放弃，每 30 秒重新探测一次，驱动起来后自动恢复。
- **健康检查不再谎报正常**：只有真正读到过数值才标为可用；AMD 卡读不到时提示安装 AMD 官方 Adrenalin 驱动（需要 `atiadlxx.dll`）。

### 新增

- **命令行显卡诊断**：`FrameForge.exe --gpudiag`
  - 输出 `atiadlxx.dll` 的实际加载路径与 15 个导出函数是否存在；
  - 输出 ADL 初始化方式（`ADL2_*` / 老式 `ADL_*`）、适配器数量，以及每个适配器上温度 / 频率 / 功耗的返回码与原始数值；
  - 结果写入 `%LOCALAPPDATA%\FrameForge\gpudiag.log` 并弹窗显示。

如果升级后仍然显示 —，请运行一次 `FrameForge.exe --gpudiag`，把 `gpudiag.log` 内容发到 Issues，日志会直接指出是 `atiadlxx.dll` 没装、还是某个接口返回了不支持。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### Fixed

- **Temperature / clock / power still showing dashes on AMD cards**: 1.4.4.1 only called the context-based `ADL2_Overdrive6_*` functions and abandoned everything on the first failure. AMD drivers differ a lot between versions, so reads now fall back twice:
  - API: `ADL2_*` (with context) first, then the legacy global `ADL_*` entry points;
  - Values: temperature via Overdrive6 → Overdrive5 → OverdriveN, clocks via Overdrive6 CurrentStatus → Overdrive5 CurrentActivity, power via the four Overdrive6 power types.
  The first path that returns a sane number is used and remembered, so no repeated probing.
- **Driver not ready at autostart**: a failed read is no longer permanent — it retries every 30 seconds and recovers once the driver is up.
- **Health check no longer reports a false OK**: the GPU row is only considered available after a real value was read, and AMD cards without a sensor are pointed at the official AMD Adrenalin driver (`atiadlxx.dll`).

### New

- **Command-line GPU diagnostics**: `FrameForge.exe --gpudiag`
  - prints the actual `atiadlxx.dll` load path and whether all 15 exports exist;
  - prints the ADL init mode (`ADL2_*` or legacy), the adapter count, and the return code plus raw value of temperature / clock / power for every adapter;
  - writes the result to `%LOCALAPPDATA%\FrameForge\gpudiag.log` and shows it in a dialog.

If values are still dashes after upgrading, run `FrameForge.exe --gpudiag` once and attach `gpudiag.log` to an issue — it shows whether `atiadlxx.dll` is missing or a specific API returns "not supported".

**Checksum**: see the attached `FrameForge.exe.sha256`.

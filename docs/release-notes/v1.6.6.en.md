# FrameForge 1.6.6

> Comprehensive stability, state-rollback, concurrency, and update-security hardening release across 32 files, keeping Zh/En localization parity at 659/659 keys.

## Highlights

- **Display & Overlay Reliability**: Fixed `Display.PathTargetInfo` struct size (+8 bytes to 48 bytes) for `QueryDisplayConfig`; added crash-safe disk persistence and startup recovery for hardware Gamma LUT and NVIDIA NVAPI Digital Vibrance; refreshed gamma HDCs on `WM_DISPLAYCHANGE`; fixed 64-bit `Rtss.ZeroMemory` `UIntPtr`, fallback `MapViewOfFile` access mask, and ANSI/DBCS truncation; cached the 1×1 probe bitmap in `Overlay.Render()`.
- **State Rollback & Concurrency**: Added `SYSTEM\GAMECONFIGSTORE` to `Tune.AllowedJournalKey()`; retained failed items in `Tune.RestoreAll()`; switched `SafeFile.WriteAllText()` to unique `.tmp` + `FileOptions.WriteThrough`; fixed `AFFINITY_MASK` `PENDING` leak on scheduler exception; enforced `Revertible` and `StartTime` guards in `BoostJournal`; added `BusyToken` generation guards in `SystemResourceArbiter`; synchronized `FpsEngine` start/stop/watchdog transitions; disposed all `Process` handles in `AffinityEngine`; eliminated per-tick reflection and tray-minimized `StateHub` polling.
- **Update Security & Desktop UX**: Used exclusive GUID updater script filenames and publisher certificate pinning in `UpdateCheck`; moved `schtasks` off the UI thread; rebuilt tray menus on theme/language switches; disposed control animation timers and enabled keyboard focus/navigation; blocked unsigned releases when SignPath signing is configured; expanded `--selftest` with HMAC tamper, missing `sum=`, and unknown schema `v=99` quarantine tests.

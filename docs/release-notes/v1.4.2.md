# FrameForge v1.4.2

## 中文

### 新增

- **加速排除名单**：输入法、触摸键盘等系统界面进程始终排除；壁纸引擎、OBS、Streamlabs、Discord 默认排除。自动加速和手动加速都会跳过名单里的程序，手动加速时会提示原因。名单在「设置 → 进程名单 → 加速排除」中逐项勾选。
- **进程优先级档位**：自定义优化项里可以选低 / 低于正常 / 正常 / 高于正常 / 高，默认「高」。选到低档会提示可能更卡，但不会阻止保存。
- **加速目标可视化**：加速中，加速页会显示目标进程名、PID、优先级档位、核心数以及是否已锁定，方便确认加速对象。
- **线程理想处理器（实验）**：只建议游戏线程使用性能核，不修改亲和性掩码，失败静默。默认关闭，自动加速不会启用。

### 改进

- 自定义优化项每个开关都有悬停说明，并新增「推荐值」按钮一键恢复默认。
- 「进程名单」弹窗改为「暂停保护 / 加速排除」两个标签页。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### New

- **Boost exclude list**: input methods and touch-keyboard shell UIs are always excluded, while wallpaper engines, OBS, Streamlabs and Discord are excluded by default. Both manual and automatic boosts skip these apps, and a toast explains why when you boost one manually. Edit the list under Settings → App lists → Boost exclude.
- **Priority levels**: the custom options dialog now offers Low / Below normal / Normal / Above normal / High (default High). Choosing a low level shows a warning but does not block saving.
- **Visible boost target**: while boosted, the Boost page shows the target process name, PID, priority level, core count and whether it is pinned, so it is easy to verify what is being boosted.
- **Thread ideal CPU (experimental)**: only hints game threads toward P-cores via `SetThreadIdealProcessor`; affinity masks are never changed and failures are silent. Off by default and never enabled by automatic boost.

### Improved

- Every custom option now has a hover description, plus a **Recommended** button to restore defaults.
- The app-lists dialog now has two tabs: **Pause protection** and **Boost exclude**.

**Checksum**: see the attached `FrameForge.exe.sha256`.

# FrameForge v1.4.6

## 中文

### 改进

- **界面去噪**：环形与弧形仪表去掉外发光、同色渐变弧和「表盘玻璃」内圈，改为一档实心色 + 一个针尖亮点；读数只在载荷超过 80% 时变红，平时回到正文色。温度 / 频率 / 功耗 / 显存四列同样不再整行飘红。
- **卡片与按钮收敛**：主按钮、导航选中胶囊、模式条下划线、预设胶囊统一为实心色面，去掉渐变高光与彩色投影；普通按钮从全胶囊改为 10px 圆角。
- **核心条重做**：未分配的核心改为中性灰刻度，只有真正被加速的核心才上色，不再整条粉色装饰。
- **雷达图**：去掉外发光与径向渐变，改为平涂数据面，形状由边缘和轴线说明。
- **新图标**：应用图标换成银色圆角底 + 白色闪电，生成 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 共九档，标题栏与托盘同步使用，16px 下仍可辨认。

### 说明

- 本次只改视觉层，功能、布局、文案与配置项均未变化，旧版本的设置文件可直接沿用。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### Improved

- **Quieter gauges**: the ring and arc gauges lost their outer glow, same-hue gradient arc and glass inner ring; each is now a single flat colour with one white tip. Readings stay in the body text colour and only turn red above 80% load. Temperature, clock, power and VRAM columns no longer go red as a row.
- **Calmer chrome**: primary buttons, the selected navigation pill, the mode-tab underline and preset chips are flat fills — no gradient highlight, no coloured drop shadow. Secondary buttons moved from a full capsule to a 10px radius.
- **Rebuilt core strip**: idle cores are a neutral grey scale and only cores that are actually boosted take the accent colour, instead of the whole bar reading as decoration.
- **Radar chart**: the outer glow and radial gradient are gone; the data face is a flat fill and the shape is described by its edge and axes.
- **New icon**: a silver rounded tile with a white bolt, rendered at 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256, used by the title bar and tray, still legible at 16px.

### Notes

- Visual-only release: features, layout, copy and settings are unchanged, and existing settings files carry over.

**Checksum**: see the attached `FrameForge.exe.sha256`.

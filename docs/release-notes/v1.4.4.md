# FrameForge v1.4.4

## 中文

### 新增

- **「我的游戏」页面**：自动扫描 Steam、Epic、GOG、卸载注册表和本机常见安装目录，把装过的游戏列在一起；双击一行直接启动，也可以关掉列表里的游戏、把它锁定为加速目标，或者把不想留的条目移除。没扫到的游戏可以用「添加 .exe」手动加进来，加进来之后识别器直接当游戏处理。
- **新游戏也能认出来**：以前只认 Steam / Epic / GOG 的安装目录，鸣潮、三角洲行动这类自己带启动器或走 WeGame 的游戏会漏掉。现在多了三条兜底——内置游戏目录名匹配（含 WeGame 的 `三角洲行动(2001918)` 这种带 appid 的目录、`WeGameApps\rail_apps`、腾讯系两层安装路径）、卸载注册表里「安装体积 ≥ 3 GB + 引擎特征 exe」、以及各固定盘常见位置的最后补扫（列表里来源显示为「本地扫描」）。
- **列表显示游戏名**：统一走真名解析，`Client-Win64-Shipping.exe` 显示为「鸣潮」，`DeltaForceClient-Win64-Shipping.exe` 显示为「三角洲行动」，WeGame 目录名后面的 `(2001918)` 也会去掉，不再把 `.exe` 或机器名摆到界面上。
- **页面细节**：鼠标悬停行会高亮，底部常驻「双击一行可直接启动」的提示，扫描时按钮显示「正在扫描本机游戏…」，扫完提示新增了几款。

### 修复

- **反作弊和启动器被当成游戏**：`AntiCheatExpert`、`BattlEye`、`EasyAntiCheat`、运行库这类目录整棵跳过；`ACE-Setup64.exe`、`launcher.exe` 以及名字以 `launcher` 结尾的程序不再作为游戏主程序；名字就叫「AntiCheatExpert」之类的卸载项直接忽略。
- **深层目录里的主程序漏检**：扫描递归深度从 3 层放宽到 5 层，`<游戏根>\xx Game\Client\Binaries\Win64\` 这种深度的真主程序现在能选中。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### New

- **A "My Games" page**: Steam, Epic, GOG, the uninstall registry and common local install folders are scanned automatically, and every installed game is listed in one place. Double-click a row to launch it, remove entries you do not want, or pin a game as the boost target. Games that were not detected can be added manually via "Add .exe" and are then treated as games by the detector.
- **Coverage for newer titles**: detection used to trust only the Steam / Epic / GOG install folders, so games with their own launcher or distributed through WeGame — Wuthering Waves, Delta Force — were missed. Three fallbacks were added: a built-in folder-name list (including WeGame's `三角洲行动(2001918)` style folders, `WeGameApps\rail_apps` and the two-level Tencent install paths), uninstall entries whose estimated size is ≥ 3 GB and whose payload looks like an engine game, and a final sweep of common locations on every fixed drive (shown as "Scanned" in the source column).
- **Real game names in the list**: names go through the shared resolver, so `Client-Win64-Shipping.exe` shows as "鸣潮" and `DeltaForceClient-Win64-Shipping.exe` as "三角洲行动"; the `(2001918)` appid suffix on WeGame folders is stripped as well. Raw `.exe` or machine names no longer reach the UI.
- **Page polish**: hovered rows are highlighted, a "double-click a row to launch" hint sits at the bottom, the scan button reports "Scanning…" while it works, and a toast reports how many games were added.

### Fixed

- **Anti-cheat components and launchers detected as games**: `AntiCheatExpert`, `BattlEye`, `EasyAntiCheat` and redistributable folders are skipped entirely; `ACE-Setup64.exe`, `launcher.exe` and anything ending in `launcher` are never chosen as the game executable; uninstall entries literally named "AntiCheatExpert" are ignored.
- **Game executables missed in deep folders**: recursion depth for executable discovery went from 3 to 5 levels, so the real binary under `<game root>\xx Game\Client\Binaries\Win64\` is found.

**Checksum**: see the attached `FrameForge.exe.sha256`.

# FrameForge 1.6.5

> 叠加层 HUD 视觉重构与可靠性加固版本。重做自绘与 RTSS 叠加层的整体观感，引入现代半透明毛玻璃 HUD 底板、五套统一配色主题与大号 FPS 主视觉，并让设置页预览与实机共用同一绘制管线；同时修复双加速资源移交落盘、并发软引导、通用进程名缓存与交互同步等多项细节问题。

## 叠加层 HUD 视觉重构

- **现代半透明 HUD 底板（默认）**：采用圆角深色纵向渐变暗底、细玻璃描边、顶部微高光与左侧主题色竖条点缀，信息区清爽醒目；可在叠加层设置页随时切换 `现代 HUD` / `轻透` / `无底板`（对应 `overlayBackdrop=hud|subtle|none`）。
- **五套统一配色主题**：新增朱砂（默认）、翠绿、粉紫、青蓝、极简五套配色（`overlayTheme=cinnabar|green|pink|cyan|mono`），自绘叠加层、RTSS 输出与设置页预览三处实时联动；旧版 `rtssColor` 中的粉/绿/青配置会自动无损迁移。
- **主次分明的排版层级**：FPS 数字放大加粗突出，`FPS` 单位缩小对齐基线；竖向模式在 FPS 主行与硬件行之间加入细水平分隔线，横向与简洁胶囊模式加入细竖线分隔；时间与时长等环境信息独立右对齐，不再拉宽 CPU / GPU 数值列。
- **RTSS 叠加层同步升级**：复用同一套五色主题，通过 `<S=...>` 内嵌字号实现 FPS 主视觉放大；逐行模式定宽对齐设备标签，单行模式改用 `|` 分隔各组指标，所有颜色标签严格 `<C>` 闭合。
- **预览与实机 1:1 统一**：设置页预览直接复用 `Overlay.PaintPreview` 测量与绘制核心，并补齐高 DPI 缩放适配，所见即所得。
- **托字阴影优化**：有底板时使用利落单层投影，无底板时使用干净四向托字描边；解锁位置时自动显示细虚线拖动框。

## 可靠性与交互修正

- **双加速资源移交落盘**：一键加速先退出并将电源/计时器所有权移交给实时加速时，实时加速立刻把新 ownership 快照写入 `boost.realtime.journal`，避免随后崩溃/强杀导致电源方案滞留高性能。
- **SHARED 叠加电源原值准确**：实时加速先开、一键加速以 SHARED 叠加时，一键加速事务日志优先读取仲裁者保存的原始电源方案，不再把当前已切换的高性能 GUID 误记为原值。
- **后台软引导防幽灵日志**：软引导后台线程在写日志前校验当前事务实例，还原加速后不会再回写旧日志，也不再强清 `steerBusy`；非 Auto 策略再平衡时同步记录理想核心变更。
- **通用进程名缓存防串名**：`Client-Win64-Shipping.exe` 等通用进程名通过目录或文件版本识别后不再写入永久纯进程名缓存，切换同类 Unreal 游戏不再沿用上一款游戏的名称。
- **字体池与配置缓存安全**：叠加层字体池回收移至帧边界执行，避免拖动缩放滑杆时在单帧渲染中途释放活跃 GDI+ 字体；保存设置后立即失效 `CoreConfig` 缓存，核心调度策略改动零延迟生效。
- **界面与开关同步修正**：
  - 修正 `Settings.Sanitize()` 加载配置时把 `overlayBackdrop=hud` 强行改回 `none` 的问题；
  - 简洁模式按实际勾选的 FPS / 1% Low / GPU 温度测量与绘制，并补齐缓存签名；
  - 桌面切换「锁定位置」开关时立刻同步显隐叠加层，方便解锁后直接拖动；
  - 快捷键 `Ctrl+Alt+O` 切换叠加层后，自绘设置卡的开关状态同步刷新；
  - 退出收尾补充停止 `warmTimer` / `updateTimer`，并释放叠加层页 `ToolTip` 句柄；
  - 调整叠加层页最小高度布局，840×640 窗口下底部不再裁切。
- **自检增强**：`--selftest` 新增叠加层 5 主题 × 3 底板 × 3 样式渲染及 RTSS 标签闭合校验，中英词条键保持 650/650 一致。

## 升级说明

- 覆盖 `FrameForge.exe` 即可，配置与战绩向后兼容。
- 首次启动 v1.6.5 时，叠加层默认启用新版「现代 HUD」底板与「朱砂」配色；若偏好之前的无底板纯文字风格，在「叠加层 → 底板」切回「无底板」即可。

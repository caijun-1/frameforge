# FrameForge v1.4.3.1

## 中文

### 新增

- **自动内存整理支持两种触发方式**：可在「设置 → 内存」里选择 **按阈值**（占用达到设定值才整理，60–95%）或 **按时间**（每隔 5–60 分钟整理一次）。两种方式都会在游戏运行或加速中自动跳过，避免把刚加载的资源清出去又读盘。

### 优化

- **设置页「内存」卡片重新排版**：触发方式选择移到标题下方左侧，不再和右上角开关重叠；阈值与间隔共用同一根滑杆，切换模式时量程、单位与标签一起变化，小窗口下也不会挤压。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### New

- **Two trigger modes for auto memory trim**: choose **Threshold** (trim only when usage reaches the configured 60–95%) or **Interval** (trim every 5–60 minutes) under Settings → Memory. Both modes are skipped while a game is running or a boost is active, so freshly loaded assets are not paged out and read back from disk.

### Improved

- **Reworked the Memory card on the Settings page**: the trigger-mode selector now sits below the title on the left instead of overlapping the switch in the top-right corner. Threshold and interval share one slider whose range, unit and label follow the selected mode, and the card still fits at the minimum window height.

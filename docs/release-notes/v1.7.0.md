# FrameForge 1.7.0

> 里程碑体验与性能引擎革命版本。引入 Win11 0.5ms 亚毫秒计时器、ISLC 级 Standby List 智能内存守卫、EcoQoS 无冻结后台驯服、powrprof.dll 原生电源引擎、实时帧时间波形图、全屏游戏内 OSD 通知、6 大主流启动器扫描与单游戏自动化全链路，中英词条扩充至 691/691 键一致。

## 核心性能引擎升级

- **Win11 托盘 0.5ms 亚毫秒计时器**：解决 Win11 22H2+ 对托盘最小化后台进程默认忽略计时器精度的隐性缺陷；优先请求 `NtSetTimerResolution(5000)`（0.5ms 精度），将帧生成等待抖动压缩至极低水平。
- **ISLC 级 Standby List 智能守卫**：解析系统物理内存真实空闲页（`ZeroPageCount + FreePageCount`），仅在真正可用内存告急时靶向清理待机缓存（Standby List），根治 16GB/32GB 机器在开放世界长局游玩中的微卡顿，且彻底避免游戏运行中误清文件缓存。
- **EcoQoS 无冻结后台驯服**：对后台高负载进程（如浏览器多进程、Electron 应用）启用 Windows 能效节流（EcoQoS）并降至低于正常优先级，将后台噪音压入 E 核与低 I/O 队列，无需冒卡死风险强制挂起，显著拉升 1% Low 帧率。
- **原生 powrprof.dll 电源引擎**：全面淘汰 `powercfg.exe` 进程拉起开销（耗时从 200ms 降至 <1ms）；在 Win11 Modern Standby (S0ix) 笔记本与掌机上无缝激活“最佳性能”电源叠加方案（Overlay Scheme），并支持对账还原。
- **热点线程实时引导**：在调度采样窗口内通过 `GetThreadTimes` 差值准确定位主线程与渲染/RHI 线程，将其分别引导至不同物理 P 核，规避同核超线程争抢。
- **反作弊友好型 IFEO 优先级**：支持将游戏配置安全写入 `IFEO\<exe>\PerfOptions` 并记录于事务日志，兼容各类严格内核反作弊。

## 游戏内叠加层、遥测与 OSD 通知

- **实时帧时间波形图（Frametime Sparkline）**：堆叠式 HUD 新增 90 采样零分配实时波形图（卡顿尖峰自动以朱砂红着色），余光即可一眼分辨微卡顿与帧节奏。
- **0.1% Low 极低帧与卡顿计数**：实时捕获 99.9 分位极低帧与离散卡顿事件，在 HUD 与赛后战报中量化偶发严重掉帧。
- **游戏内热键与加速 OSD 通知**：按 `Ctrl+Alt+B/F/O` 或触发自动加速时，在游戏全屏角落弹出极简电竞风 OSD 提示与量化收益战报，不抢焦点、无需切屏。
- **GPU 硬件级热墙/功耗墙诊断**：接入 NVML 降频诊断，显卡触发过热降频或功耗墙时即时标注 `THRM` / `PWR` 徽标。
- **单游戏全链路自动化**：进游戏自动套用单游戏专属核心调度、画面滤镜（内置 8 大专属滤镜联动）与叠加层显隐，退游戏秒级无损还原。

## 桌面交互、生态库与全平台扫描

- **首页就绪检查条**：首次启动或未就绪时自动提示提权或一键下载 PresentMon，30 秒零门槛看到真实 FPS。
- **量化加速战报与双态实效胶囊**：加速后直观展示释放内存大小、驯服后台数与各组件真实生效状态。
- **托盘 6 项快捷控制台**：右键托盘支持快速开关叠加层、滤镜、切换野兽/均衡模式、一键清内存与加速/还原。
- **统一反作弊保护中心**：抽离 `ProcessGuardList` 单一事实来源，全面覆盖 EA AntiCheat、网易 NeacSafe、Vanguard 等最新反作弊与外设驱动。
- **2024–2026 热门游戏库与 6 大启动器原生扫描**：内置库扩充近百款新游；新增 Xbox (PC Game Pass)、米哈游 HoYoPlay、暴雪 Battle.net、Riot、EA App、Ubisoft、WeGame 原生扫描并支持 `LaunchUri` 原生协议启动。
- **系统诊断页一键撤销**：优化页新增就地一键安全撤销优化改动，不干扰进行中的游戏加速。
- **赛后战报历史基线对比**：战报卡自动对比同游戏近 10 局历史均值，直观查看帧率增益与温度变化。

## 升级说明

- 覆盖 `FrameForge.exe` 即可直接升级，所有旧版配置、单游戏策略与战绩历史自动无损兼容。

# FrameForge 1.7.0 (English)

> A milestone release introducing sub-millisecond timer resolution, ISLC-grade standby list memory guarding, EcoQoS non-freezing background throttling, native powrprof.dll power management, live frametime sparklines, in-game OSD toast notifications, 6 major launcher scanners, and full per-game automation (bilingual parity at 691/691 keys).

## Core Performance Engine Upgrades

- **Win11 Sub-Millisecond 0.5ms Timer**: Bypasses Windows 11 22H2+ tray timer throttling via `SetProcessInformation(ProcessPowerThrottling)` and requests `NtSetTimerResolution(5000)` (0.5ms) for rock-solid frame pacing.
- **ISLC-Grade Standby List Guard**: Evaluates real available memory (`ZeroPageCount + FreePageCount`) and purges only the Standby List when true free memory runs critically low, eliminating stutter in long open-world gaming sessions.
- **EcoQoS Non-Freezing Background Throttling**: Applies Windows Efficiency Mode (EcoQoS) and below-normal priority to background hogs (browsers, Electron apps), routing background noise to E-cores and low-priority I/O without risk of freezing apps.
- **Native powrprof.dll Power Engine**: Replaces slow `powercfg.exe` calls with `<1ms` native Win32 APIs, natively activating the High Performance Power Overlay Scheme on Win11 Modern Standby (S0ix) laptops and handhelds.
- **Real Hot-Thread Steering**: Identifies the primary game loop and rendering/RHI threads via `GetThreadTimes` deltas and steers them to distinct physical P-cores.
- **Anti-Cheat Friendly IFEO Priority**: Supports safe per-game CPU/IO priority persistence in `IFEO\<exe>\PerfOptions` backed by `tune.journal` rollback.

## In-Game Overlay, Telemetry & OSD

- **Live Frametime Sparkline**: Compact 90-sample real-time graph rendered on the stacked HUD with amber/cinnabar highlighting on stutter spikes.
- **0.1% Low & Stutter Counter**: Captures the 99.9th percentile low FPS and discrete hitch counts in real time.
- **In-Game OSD Toast Notifications**: Displays crisp, non-activating esports-style notifications when hotkeys (`Ctrl+Alt+B/F/O`) or auto-boost trigger.
- **GPU Thermal/Power Throttling Indicator**: Live NVML badge flags (`THRM` / `PWR`) diagnosing GPU throttle causes on the fly.
- **Per-Game Automation Pipeline**: Automatically activates customized core policies, screen filters (synced with the 8 built-in game presets), and overlay modes on game launch, and cleanly restores desktop defaults on exit.

## Desktop Experience & Launcher Ecosystem

- **Readiness Banner**: Automatically prompts for one-click elevation or PresentMon setup on first launch.
- **Quantified Boost Summary & Dual-State Chips**: Real-time reports of freed RAM, tamed background processes, and active features.
- **6-Item Tray Quick Console**: Quick toggles for boost/restore, beast/balanced mode, overlay, filters, and RAM trimming from the tray.
- **Unified ProcessGuardList**: Covers the latest 2024–2026 anti-cheat suites (EA AntiCheat, NetEase NeacSafe, Vanguard, etc.) and peripheral software.
- **2024–2026 Game Database & 6 Native Launchers**: Adds 95+ new titles and native read-only scanning for Xbox / PC Game Pass, HoYoPlay, Battle.net, Riot Client, EA App, Ubisoft Connect, and WeGame with native `LaunchUri` execution.
- **In-Place Health Revert**: Safe rollback button on the Health page without touching active game boost.
- **Post-Match Baseline Comparison**: Compares match stats against the player's 10-match historical baseline.

## Upgrade Notes

- Simply replace `FrameForge.exe`. All settings, game profiles, and session histories are backward-compatible.

# FrameForge v1.6.0

**质量与安全版本。** 在 1.5.1 的一批 P0/P1 热修之上，完成评审报告里留给 1.6.0 的架构项：资源仲裁死锁、高 DPI 对话框、CPU 负载采样、系统文件缓存、NVAPI 调用安全、HDR/ACM 检测与日志隐私；画面滤镜按参数规范重新标定了全部 23 套预设。

下载：`FrameForge.exe`（Windows 10/11，.NET Framework 4.8，单文件免安装，首次运行需管理员权限）。

## 画面滤镜

- **修正颜色矩阵方向**：内部按列向量构造矩阵，导出到 Win32 `MAGCOLOREFFECT` 与 GDI+ `ColorMatrix` 前统一转置。此前后处理预览与实屏效果方向相反，现在两者一致。
- **23 套预设重新标定**：按《画面滤镜参数优化方案》逐项调整饱和度、对比度、亮度、色温与暗部补偿，索引 0–22 顺序不变，用户已保存的预设引用不会错位。雾天增强改为轻微降饱和去雾方向，夜间护眼落在暖色安全区。
- **色温连续化**：由三个固定白点改为普朗克黑体轨迹插值，滑杆改用 Mired（±75），整体范围收紧到 2700–10000K，避免低色温端偏绿。
- **安全区间**：饱和度正负半轴分别限幅（工作区 1.45、总上限 1.65），净黑位不超过 +0.055；强度只在最终合成后插值一次，不再出现叠加插值导致的偏色。
- **HDR / 自动颜色管理检测**：通过 `DisplayConfigGetDeviceInfo` 读取高级颜色状态，开启时在滤镜页明确提示「系统会绕过色调调整」，并在分辨率、刷新率或显示器变化后自动重测。

## 安全

- 所有系统程序（powercfg、schtasks、shutdown、explorer 等）改用 System32 绝对路径启动；进程启动前调用 `SetDefaultDllDirectories` 把 DLL 搜索目录锁定到 System32，杜绝便携目录下的同名 DLL 劫持。
- RTSS 安装包每次下载到随机目录并强制校验 SHA-256，不再复用 `%TEMP%` 里的旧解压结果；自更新包在启动安装器前重新计算哈希；PresentMon 必须带有效 Intel 签名才允许启动。
- 加速日志增加 HMAC 签名（密钥保存在 `%ProgramData%\FrameForge`），手工改写的日志无法触发还原；优化项读取改为白名单键，电源方案校验 GUID 格式。
- 配置文件加载即钳位：滤镜参数、ICC 路径（拒绝 UNC、相对路径与超长路径）、ICC 列表数量与叠加层缩放全部限幅，损坏配置不会再拖垮启动。
- NVAPI 只绑定语义明确的 `SetDVCLevel`，移除会把结构体指针当等级传入的 `SetDVCLevelEx` 变体，以及 Optimus 机器上会写错显示器的物理 GPU 句柄回退；释放时补调 `NvAPI_Unload`。
- ICC 解析修复：增加 16MB 上限、偏移写入正确的通道槽、曲线与参数曲线改用 `long` 计算并做 4 字节对齐，避免越界与错位。

## 稳定与性能

- **资源仲裁者重构**：锁内只做状态转移，读原值、写系统、写回与 owner 回调全部移到锁外，消除一键加速与实时加速之间的 AB-BA 死锁；holder 转移时立即落盘新的归属，崩溃恢复不会再认错负责人。
- **混合架构判定**：P/E 核频率差达到 10% 才判为混合架构，同构平台保持原判定；Intel 核显/大小核机器不再因 `EfficiencyClass` 语义差异误判。
- **CPU 负载采样**：改为「内核时间 − 空闲时间 + 用户时间」，空载核心不再显示成半忙，核心图与雷达读数同步修正。
- **理想处理器**：不再把所有线程塞进同一颗核，按可用核轮流分配，主线程优先落到采样出的空闲核；每轮只在结束时落盘一次日志。
- **实时加速开销**：每 5 秒的进程扫描由 13 次按名查询合并为一次全表枚举；提权失败的 PID 进入 5 分钟冷却，不再反复写两条日志；动作记录超过 256 条时优先裁剪已还原项。
- **内存整理**：只在全屏游戏时清理待机列表，并与实时加速共享 30 秒节流；进程裁剪改为按工作集降序，先归还闲置大进程，不再拿小工具开刀。
- **系统文件缓存**：改用 `SetSystemFileCacheSize(-1, -1, 0)`，旧实现传入全零缓冲会被内核判为参数非法，永远返回失败。
- **中断优化**：只删除自己写入的 `DevicePolicy` / `AssignmentSetOverride`，不再整键删除；未显式开启 MSI 的设备不再被当作已开启。
- **MPO 开关**：修正反转逻辑——开启时删除覆盖值，关闭时才写回。
- **退出路径**：关机/注销与窗口关闭时先撤全屏滤镜、gamma LUT 与背光，再还原系统项。
- **高 DPI 对话框**：对话框按正文实际换行高度撑开，正文区域跟随窗口尺寸，不再出现文字被按钮压住；危险确认对话框（清理、还原、结束进程）回车等于取消。

## 隐私与日志

- 日志分级为 INFO / WARN / ERROR，可用 `FRAMEFORGE_LOG_LEVEL` 环境变量过滤。
- 所有日志单行化（换行转为 ` | `），用户目录与用户名自动替换为 `%USERPROFILE%` / `%USER%`，单行超长截断。
- 主程序与看门狗通过命名互斥量串行写日志；单实例互斥量从 `Global\` 改为 `Local\`，多用户/远程桌面下不再互相挡住。

## 界面

- 主题按钮按当前主题显示太阳或月牙，切换主题立即重绘。

## 自检

- 新增滤镜四项检查：灰度中性、行向量导出、夜间亮度范围、CS2 暗部抬升。
- 新增高级颜色探测信息行（off / supported / hdr / acm）。
- 新增仲裁器并发回归：两个 owner 交替抢占计时器 60 次往返，验证无死锁、无引用计数泄漏。

## 已知限制

- 混核绑核、NVIDIA DVC、高 DPI 与 HDR 实屏效果仍需对应真机验证。
- HDR/ACM 开启时 Windows 会绕过 SDR 色调调整，这是系统行为，滤镜页只做提示。

## 升级说明

直接替换旧版 `FrameForge.exe` 即可，配置与加速日志自动兼容。若从 v1.5.x 升级，首次启动会沿用原有设置。

# FrameForge v1.4.3.5

## 中文

### 修复

- **反作弊组件不再被当成游戏**：BattlEye Launcher、ACE-Helper、EasyAntiCheat、ACE-Guard 等进程会弹出全屏窗口，又和游戏装在同一目录下，之前会被记进战绩并被自动加速，甚至顶替掉真正的游戏。现在进程名与安装目录两条判定路径都排除这些组件，旧版本已经写进战绩的历史记录在读取时直接丢弃。
- **显卡驱动异常时不再拖垮程序**：驱动复位或驱动本身出错时，`nvml.dll` 可能直接抛访问违例（CSE），普通 `catch` 接不住会让 FrameForge 整个退出。现在这类异常会被捕获，随后停用显卡数据采集（界面显示 `—`），帧率、加速、内存整理等功能照常可用。
- **帧率长时间不显示**：界面心跳里对已被释放的进程对象读取 `HasExited` 会抛异常，导致刷新中断；同时多个采集看门狗线程会互相杀掉对方刚启动的 PresentMon、反复拆建 ETW 会话，第一行数据永远等不到。现在旧看门狗自动退出，失败按 10/20/40 秒退避，连续 6 次仍拿不到数据才停止重试并写日志。

> 说明：带内核级反作弊的游戏（如鸣潮的 ACE / KRSDK）会拦截 ETW 呈现事件，这种情况下帧率无法采集，日志会记录 `presentmon giving up ... (frame capture blocked?)`。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### Fixed

- **Anti-cheat components are no longer mistaken for games**: BattlEye Launcher, ACE-Helper, EasyAntiCheat and ACE-Guard open full-screen windows and live under the game folder, so they used to be recorded as game sessions and auto-boosted, sometimes replacing the real game. They are now excluded by both process name and install path, and stale entries already written to the records are dropped on load.
- **A faulty GPU driver can no longer take the app down**: when the driver resets or misbehaves, `nvml.dll` can raise an access violation (CSE) that a plain `catch` cannot intercept, which used to terminate FrameForge. The exception is now handled, GPU stats stop updating (shown as `—`), and FPS, boost and memory features keep working.
- **FPS could stay blank for a long time**: reading `HasExited` on a disposed process object threw inside the UI heartbeat and broke the refresh, while several watchdog threads kept killing each other's PresentMon and tearing down the ETW session, so the first data row never arrived. Old watchdogs now retire, failures back off at 10/20/40 s, and collection stops with a log entry after six consecutive empty attempts.

> Note: games with kernel-level anti-cheat (such as Wuthering Waves' ACE / KRSDK) block ETW present events, so FPS cannot be collected there. The log records `presentmon giving up ... (frame capture blocked?)` in that case.

**Checksum**: see the attached `FrameForge.exe.sha256`.

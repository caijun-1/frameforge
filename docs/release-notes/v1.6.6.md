# FrameForge 1.6.6

> 稳定性、状态回滚闭环与工程安全全面加固版本。针对底层显示拓扑、硬件滤镜崩溃恢复、事务日志回滚、监控线程并发与低功耗、更新器校验及桌面无障碍交互进行了系统性优化，中英词条同步扩充至 659/659 键一致。

## 显示、滤镜与叠加层加固

- **修复多屏 HDR 探测结构体对齐**：补齐 `Display.PathTargetInfo` 缺失的 8 字节字段（`TargetAvailable` 与 `StatusFlags`），匹配 Win32 `DISPLAYCONFIG_PATH_TARGET_INFO`（48 字节），消除 `QueryDisplayConfig` 缓冲区错位风险。
- **硬件 Gamma LUT 与 NVIDIA DVC 崩溃兜底恢复**：调整画面伽马或数字振动前原子落盘原始状态，异常退出或崩溃后下次启动自动执行 `RecoverStale()` 还原，不留桌面偏色/过饱和残留。
- **显示拓扑热更新与 RTSS 修复**：监听 `WM_DISPLAYCHANGE` 重新获取显示器 HDC；修复 RTSS `ZeroMemory` 64 位 `UIntPtr` 签名、`OpenFileMapping` 只写回退权限掩码不匹配、`Clear()` 锁外修改状态及 ANSI/DBCS 字符边界截断问题。
- **叠加层零每帧位图分配**：`Overlay.Render()` 复用 1×1 探针位图与画布，减少高帧率刷新下的 GDI+ 垃圾回收。

## 状态回滚与并发性能

- **DVR 恢复与事务日志原子化**：`Tune.AllowedJournalKey()` 补全 `SYSTEM\GAMECONFIGSTORE` 支持重启后恢复 Game DVR；`Tune.RestoreAll()` 逐项核验电源方案与注册表写回结果，失败时保留日志；`SaveJournal()` 全面改用 `SafeFile.WriteAllText()`（唯一 `.tmp` + `WriteThrough` 落盘）。
- **调度与仲裁闭环**：`BoostEngine.Apply()` 在核心调度异常分支补全 `Confirm(..., false)` 避免事务卡死在 `PENDING`；`BoostJournal` 严格消费 `Revertible` 契约并在 `StartTime <= 0` 时拒绝盲信 PID 还原；`SystemResourceArbiter` 引入 `BusyToken` 代际计数防止超时后错清状态。
- **PresentMon 启停与后台低功耗**：`FpsEngine` 启停与看门狗切换纳入 `startGate` 锁消除孤儿进程；最小化至托盘时跳过 `StateHub.RefreshFromEngines`，取消 `coreScheduler` 每 tick 反射；`AffinityEngine` 确保全量释放 `Process` 句柄；`Monitor` 监听网卡变化自动刷新；`PdhCounter` 复用缓冲区减少每秒装箱。

## 更新安全、UI 与工程卫生

- **更新器安全增强**：使用随机 GUID `.cmd` 临时脚本防范 `%TEMP%` 劫持；比对更新包签名发布者证书与当前程序一致；下载失败自动清理临时文件；修复更新弹窗回车跳过安装的问题。
- **桌面体验与无障碍**：`schtasks` 开机自启移至后台线程消除 UI 卡顿；语言/主题切换同步重建托盘菜单；为自绘控件补全动画定时器释放与 `TabStop` 键盘焦点操作；修复 `WM_DPICHANGED` 最小尺寸更新顺序；新增未决日志 UI 提醒。
- **CI 与自检扩展**：发布流在配置签名但失败时阻断静默发包；`--selftest` 新增 HMAC 篡改、缺失 `sum=`、未知 schema `v=99` 隔离回归及版本比较用例，跳过项不再计入 PASS。

## 升级说明

- 覆盖 `FrameForge.exe` 即可，配置文件与历史战绩向后兼容。

# FrameForge 1.6.6 (English)

> Comprehensive stability, state-rollback, concurrency, and update-security hardening release across 32 files, keeping Zh/En localization parity at 659/659 keys.

## Display, Filters & Overlay Hardening

- **Fixed Multi-Monitor HDR Detection Struct Layout**: Added the missing 8 bytes (`TargetAvailable` and `StatusFlags`) to `Display.PathTargetInfo`, matching Win32 `DISPLAYCONFIG_PATH_TARGET_INFO` (48 bytes) and eliminating `QueryDisplayConfig` buffer misalignment.
- **Crash-Safe Hardware Gamma LUT & NVIDIA DVC Recovery**: Atomically persists original Gamma LUT and NVIDIA Digital Vibrance levels before applying changes, and automatically runs `RecoverStale()` on startup to restore desktop color state after crashes or forced exits.
- **Display Topology Hot-Refresh & RTSS Fixes**: Re-acquires monitor HDCs on `WM_DISPLAYCHANGE`; fixed 64-bit `UIntPtr` signature in `Rtss.ZeroMemory`, fallback `MapViewOfFile` access mask mismatch, unsynchronized `Clear()`, and ANSI/DBCS truncation; cached the reusable 1×1 probe bitmap in `Overlay.Render()`.

## State Rollback & Concurrency Performance

- **DVR Restore & Atomic Journal Writes**: Added `SYSTEM\GAMECONFIGSTORE` to `Tune.AllowedJournalKey()` for Game DVR restoration; retained failed items in `Tune.RestoreAll()`; switched journal writes to `SafeFile.WriteAllText()` (unique `.tmp` + `WriteThrough`).
- **Scheduler & Arbiter Closure**: Added `Confirm(..., false)` on scheduler exceptions in `BoostEngine.Apply()` to prevent `AFFINITY_MASK` from staying `PENDING`; enforced `Revertible` and `StartTime` guards in `BoostJournal`; added `BusyToken` generation counters in `SystemResourceArbiter`.
- **PresentMon Lifecycle & Low Tray Overhead**: Synchronized `FpsEngine` start/stop/watchdog transitions under `startGate`; skipped `StateHub.RefreshFromEngines` when minimized to tray and removed per-tick `coreScheduler` reflection; disposed all `Process` handles in `AffinityEngine`; auto-refreshed NICs on `NetworkAddressChanged`; reused `PdhCounter` buffers.

## Update Security, Desktop UX & CI

- **Hardened Auto-Updater**: Uses exclusive GUID `.cmd` scripts to prevent `%TEMP%` hijacking, pins signer certificate to the current executable publisher, cleans up partial downloads on failure, and fixes `Enter` key skipping installation in `UpdateDialog`.
- **Desktop UX & Accessibility**: Moved `schtasks` autostart calls off the UI thread; rebuilt tray menus on theme/language switches; disposed control animation timers and enabled `TabStop` keyboard focus/navigation; fixed `WM_DPICHANGED` minimum size ordering; added UI alerts for pending journals.
- **CI & Self-Test Expansion**: Blocked unsigned releases when SignPath signing is configured; expanded `--selftest` with tampered HMAC, missing `sum=`, and unknown schema `v=99` quarantine checks, plus `UpdateCheck.Compare` unit assertions.

## Upgrade Notes

- Simply replace `FrameForge.exe`; existing settings and match records remain backward-compatible.

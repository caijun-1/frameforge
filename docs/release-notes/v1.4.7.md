# FrameForge v1.4.7

## 中文

### 改进

- **实时加速更省资源**：守护循环不再每秒枚举整张进程表。前台窗口仍按 1 秒检测，常用程序与同名进程统计降到每 5 秒一次，前台没变化时直接跳过重复的枚举与提权，常驻时的 CPU 开销明显下降。状态里的加速程序与进程数照常刷新。
- **实时加速状态换了位置**：不再挤在底部模式条里，改为显示在加速页左上角「未加速」右侧，和其它加速状态放在同一行；关闭时只显示「实时加速 · 关闭」，悬停可看开关说明。底部模式条因此更矮，仪表区域多出一行空间。
- **界面去臃肿**：设置页的开关行去掉重复副标题改为单行，常规卡更紧凑；叠加层说明卡去掉重复标题；优化页说明文字降为中性灰，只有异常项标红；「我的游戏」扫描时按钮改用「扫描中…」，不再溢出。
- **文案精简**：加速、我的游戏、滤镜、叠加层、优化、设置的中英文说明统一缩短，长解释收进悬停提示。

### 新增

- **叠加层帧时间**：显示内容新增「帧时间 ms」，「1% Low」标注统计窗口为 5 秒。
- **滤镜左右分屏对比**：预览常驻显示原图与当前效果，拖动中间分界线即可比较，参数调整实时反映在预览上。

**完整校验值**：见附件 `FrameForge.exe.sha256`。

## English

### Improved

- **Lighter real-time boost**: the background loop no longer walks the whole process table every second. The foreground window is still checked once per second, while common apps and same-name process counts refresh every five seconds, and repeated work is skipped when the foreground has not changed. The boosted app and process count keep updating as before.
- **Status moved**: the real-time boost status now sits next to the boost state in the top-left of the Boost page instead of the bottom mode bar, which is now shorter. Hover it to see where the switch lives.
- **Less clutter**: settings toggles are single-line rows, the overlay note card no longer repeats its header, health notes are neutral grey with red only for problems, and the games scan button uses a short "Scanning…" label.
- **Shorter copy** across Boost, Games, Filter, Overlay, Health and Settings in both languages, with long explanations moved into tooltips.

### Added

- **Frame time in the overlay**, and "1% Low" now states its 5-second window.
- **Split filter preview**: the original and the current look are always shown side by side; drag the divider to compare, and slider changes update the preview live.
